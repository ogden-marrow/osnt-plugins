Privacy. Running an investigation sends the image (or its URL) to third-party services: Google Cloud Vision and/or SerpAPI (Google Lens) for reverse image search, and the search results and page text (never the image itself) to DeepSeek for analysis. Nothing is sent until you press Run investigation. The Pi never stores the image.
People. This tool does not identify people from their faces or appearance and does not use face recognition. If a source names someone, the report only repeats what that source says. Reliability. "Earliest found" is not "original". Treat the result as leads for a human to check.
