Admin token

Get it from your machine with cargo deploy token. It is kept in this tab only (session storage) and sent with each request.

Values are write-only: they are stored on the Pi (mode 0600) and handed only to plugins that declare them in their manifest; they are never shown here again. This site is served over plain HTTP on your network, so only use it on a network you trust (or through an SSH tunnel / VPN) until HTTPS is added.
